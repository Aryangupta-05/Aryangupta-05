**Python · FastAPI · PostgreSQL · Redis · FAISS · LangChain · React · Docker**

### 💬 [Tweetie — Social Platform with an AI Writing Assistant](https://github.com/Aryangupta-05/Tweetie)

**React · Node.js · Express · MongoDB · Gemini · JWT · AWS S3**

- Built authenticated social features, bookmarks, search, and a feed ranked by a background worker.
- Integrated **Gemini draft improvement** with a suggestion preview: authors choose whether to apply an edit before publishing. API credentials stay on the server.
- Added regression tests covering draft validation, provider errors/timeouts, truncated output, response shape, and literal/hashtag search.
- Integrated S3 media storage, TanStack Query caching, and EC2/PM2 deployment tooling.
